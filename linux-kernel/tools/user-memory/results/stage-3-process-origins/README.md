# Stage 3 process emission and potential-access source index

`TOPAL-SYSTEMS-USER-EXTENT-001`, `TK-DEC-283`.

The [summary](origin-summary.json) joins the selected linked process graph's
14584 potential-access instructions to 9380 source locations in 50 emitter
files. The test-only producer records 45005 contiguous, nonoverlapping emission
spans covering all 231663 function bytes, including embedded data and fixup
fields. Register/memory encoder wrappers propagate caller locations so access
opcodes point to their semantic emitter call sites rather than generic encoder
methods. [Independent expansion](readback.json) checks every byte's span assignment
and every listed graph access; no access is omitted from the join.

The join independently applies all 19 process-function ELF relocations and
requires its complete provider-object payload to reconstruct the linked
function exactly. It verifies actual instruction bytes, all listed source-file
hashes and source-line bounds before attaching locations and nearby labels.
The [writer index](writer-index.md) groups the exact selected records for review;
full spans, source excerpts and access rows are compressed under
[artifact identities](artifact-identity.json).

These are **emission/append origins**, not a complete write history or compiler
semantic proof. A nested generated byte vector points to its append site;
local fixup fields retain their original emission attribution. One array append
can contain multiple instructions, and one instruction can span multiple source
expressions. Nearby labels are context, not a control-flow or ownership proof.
None of this metadata grants kernel access or execution authority.

An initial source review distinguishes 1006 instructions emitted at completion
lines 1682/1685: they normalize Accessed/Dirty status across 503 private leaf-table
entries. They are not application-buffer copies. Their actual table ownership,
entry conditions and cleanup lifetime still require their own contracts.
The largest general-address groups also include sealed startup/stack checks;
these must remain distinct from arbitrary syscall buffer admission. No safety
classification follows merely from an RSP/RBP base, a GS operand, a source file
name, a successful helper call or an observed first reach.
