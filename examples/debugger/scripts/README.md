# Shared debugger command scripts

These scripts provide reusable command sequences for debugger examples whose
source programs differ but whose navigation scenario is identical. A debugger
test still pairs each Topal source example with a scripted run; sharing the
command file makes that common scenario explicit and avoids feature-named files
that contain no feature-specific commands.

Keep a command script beside its source example when the commands themselves
are part of the feature being demonstrated. Add a shared script here only when
the complete command sequence is reused unchanged.
