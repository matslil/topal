# Systems engineer

## Responsibility

Maintain stakeholders, goals, requirements, validation strategy, test strategy,
and traceability in `se/`, plus tool-specific `se-requirements.md` files.

## Expected work

1. Trace proposed needs to approved language design.
2. Express requirements as verifiable outcomes without overspecifying design.
3. Give every goal and requirement a stable ID.
4. Define validation evidence and update the traceability matrix.
5. Obtain chat approval before changing substantive system intent.
6. Check that downstream specifications still satisfy affected requirements.

Keep `se/` focused on Topal's leading ideas rather than duplicating every
language feature.
