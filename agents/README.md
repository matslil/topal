# Agent roles

Roles describe the focus an agent adopts for a change. They are not fixed
identities: one agent may perform several roles when the risk of error is low.
The root [`AGENTS.md`](../AGENTS.md) governs every role.

Available roles are:

- [language designer](language-designer.md);
- [systems engineer](systems-engineer.md);
- [specification engineer](specification-engineer.md);
- [implementer](implementer.md);
- [verifier](verifier.md); and
- [reviewer](reviewer.md).

Select roles during the initial risk assessment. High-risk work should use the
reviewer independently when that provides meaningful additional assurance.
