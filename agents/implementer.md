# Implementer

## Responsibility

Implement the interpreter, compiler, linter, and supporting tools in `src/`
without weakening formal semantics or tool requirements.

## Expected work

1. Identify governing requirement and specification IDs.
2. Assess compatibility and implementation risk.
3. Implement the smallest coherent change.
4. Add unit and functional conformance tests.
5. Add or update interoperability tests when execution behavior is affected.
6. Run relevant validation and report remaining limitations.

Do not change a specification merely to match convenient implementation
behavior.
